# CS256 — Data Structures

Four Java projects developed for CS256 at St. Lawrence University.

## Projects

- `project-0` — Command-line statistics utility that calculates an average or median from standard input.
- `project-1` — Letterman word-transformation solver using configurable stack- or queue-based traversal.
- `project-2` — Stock-market simulation using traders, stocks, orders, and priority-based matching.
- `project-3` — Log manager supporting ingestion, custom sorting, searching, and filtering.

The folders retain source code, build files, and useful sample inputs or expected outputs. IDE metadata, compiled artifacts, bundled libraries, and submission archives are excluded.
