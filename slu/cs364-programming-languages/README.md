# CS364 — Programming Languages

The `snail-language` directory preserves a semester-long implementation of the educational Snail programming language, developed with Anja Simić.

## Stages

- `p1a` and `p1b` — Functional programming and data-structure exercises in ReasonML.
- `p2` — Topological sorting with cycle detection, implemented in Snail with a Python reference implementation.
- `p3` — Java/JFlex lexer that converts Snail source into a token stream.
- `p4` — Python/PLY parser that turns lexer output into an abstract syntax tree.
- `p5` — ReasonML interpreter implementing environments, stores, scoping, inheritance, and method dispatch.

Source, project documentation, citations, and relevant tests are included. Generated executables, caches, archives, and classroom examples are excluded.
