# 8088 Breadboard Computer

A physical computer built around an 80C88 processor across four milestones:

1. Created a minimal bootable image and experimented with assembly- and C-based kernels.
2. Wired the processor, clock generator, ROM, and SRAM on breadboards.
3. Added memory-mapped LCD output and programmed a custom message into ROM.
4. Integrated interrupts, timing, serial I/O, CompactFlash storage, and a speaker, then verified POST and BIOS boot behavior.

`lab1-source` contains the surviving source code and reproducible build configuration. Compiled binaries, disk images, object files, and course handouts are intentionally excluded.
