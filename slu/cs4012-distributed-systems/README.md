# CS4012 — Distributed Systems

Course projects exploring concurrency, synchronization, network programming, and distributed collective operations in C#.

## Projects

| Project | Focus |
| --- | --- |
| `chat-room` | TCP networking, asynchronous client handling, and synchronized message distribution |
| `intersection` | Thread coordination, concurrent queues, monitors, and traffic-flow simulation |
| `parallel-permutations` | Thread-pool parallelism, synchronization events, and result aggregation |
| `progressive-sudoku` | Concurrent Sudoku-solving implementation |
| `collective-operations` | Broadcast, gather, reduce, and scatter communication patterns |

Only project source and explanatory documentation are included. Lecture notes,
assignment handouts, generated output, build artifacts, editor settings, and
intermediate drafts are excluded from version control.
