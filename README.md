# Projects

A collection of coursework and independent software projects.

## St. Lawrence University

### CS256 — Data Structures

- **Statistics CLI** — Command-line average and median calculator with input validation and option parsing.
- **Letterman** — Word-transformation path finder supporting stack- and queue-based searches.
- **Stock Market Simulation** — Priority-queue simulation of traders, stocks, and matched buy/sell orders.
- **Log Manager** — Searchable log processor with custom sorting and filtering operations.

### CS364 — Programming Languages

- **Snail Language Toolchain** — Progressive language implementation covering functional programming, graph algorithms, lexical analysis, parsing, AST construction, and interpretation.

### CS450 — Computer Architecture

- **8088 Breadboard Computer** — Bootloader and kernel experiments accompanying a physical 80C88 computer build with ROM/SRAM, LCD output, interrupts, timers, serial I/O, CompactFlash storage, and BIOS booting.

### CS4012 — Distributed Systems

- **Chat Room** — Multi-client TCP chat application with concurrent send/receive tasks and a synchronized message queue.
- **Intersection** — Multithreaded traffic-intersection simulation using concurrent queues, locks, and monitors.
- **Parallel Permutations** — Parallel string-permutation generator using the .NET thread pool and manual reset events.
- **Progressive Sudoku** — A Sudoku solver developed through a sequence of increasingly concurrent implementations.
- **Collective Operations** — Broadcast, gather, reduce, and scatter exercises for moving data across distributed processes.

The repository contains project source and explanatory documentation; lecture
notes, assignment handouts, build output, and intermediate drafts are excluded.
